RoFormer：带旋转位置嵌入的增强 Transformer

RoFormer: Enhanced Transformer with Rotary Position Embedding

Jianlin Su，Yu Lu，Shengfeng Pan，Ahmed Murtadha，Bo Wen，Yunfeng Liu（追一科技）

摘要

位置编码有助于建模序列中不同位置的依赖。本文梳理多种注入位置信息的方式，并提出旋转位置嵌入（RoPE）：用旋转矩阵编码绝对位置，同时在自注意力中显式体现相对位置依赖。RoPE 具有长度灵活、随相对距离衰减的交互、以及可为线性注意力配备相对位置等性质。在长文本分类等基准上，RoFormer 稳定优于对照；文中给出理论分析，实现已进入 Hugging Face。

1 核心构造

把偶数维特征两两分成平面，对 query / key 按位置角 \(\theta_m\) 旋转。关键恒等式是：

\[\langle R_{m}q,\,R_{n}k\rangle = \langle q,\,R_{n-m}k\rangle,\]

即点积只依赖相对位移，同时又由绝对位置的旋转生成，无需额外相对偏置参数表。

2 性质

  • 序列长度可外推（实践中常配合插值或 NTK 等技巧）。
  • 相对距离增大时，依赖倾向于衰减。
  • 与线性注意力等变体兼容较好。

3 影响

LLaMA 及大量开源 LLM 默认 RoPE。可与 Shaw 相对位置（显式边表示）、ALiBi（分数上的距离惩罚）对照：目标都是「让注意力知道远近」，机制不同。
