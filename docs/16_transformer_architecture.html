Transformer 技术全景与详细架构图

第 15 课亲手拼过一个小 Transformer。这一课不跑代码，把完整 Transformer 用到的每一项技术汇总起来： 原论文的编码器–解码器结构、注意力内部的每一步、块的两种写法、训练配方、推理加速，以及后来演化出的常见变体。 每一项都标出它在本项目哪一课里实现过，没实现过的也写清楚做什么、为什么。

怎么读这一课

  • 先看架构图：左边两栏是原论文的编码器（左）和解码器（右），数据自下而上流动；右侧六个面板是各模块的内部和变体。
  • 图里每个框右上角的蓝色标签（如 L14）表示本项目第 14 课里亲手写过这个零件，可以回去对照代码。
  • 再按下面的分类表逐项读。表格的“本项目”一列为空，说明本项目没有实现它，只需要知道它解决什么问题。

一次前向传播：张量形状怎么变

以翻译为例。B 是批大小，S、T 是源句和目标句长度，d 是模型宽度（原论文 512），h 是头数（8），V 是词表大小。

源句 token id         (B, S)
  → 嵌入 × √d + 位置编码 (B, S, d)
  → N 个编码器层         (B, S, d)        每层：自注意力 → Add & Norm → FFN → Add & Norm
  = memory              (B, S, d)

目标句右移一位         (B, T)            <bos> y₁ … y_(T−1)，训练时用真值（teacher forcing）
  → 嵌入 × √d + 位置编码 (B, T, d)
  → N 个解码器层         (B, T, d)        每层：带因果掩码的自注意力 → 交叉注意力(K、V = memory) → FFN
  → Linear d → V        (B, T, V)        logits
  → softmax             (B, T, V)        每个位置一个词表分布，和真值 y₁ … y_T 算交叉熵

注意力内部：Q、K、V   (B, h, T, d/h)    分数 Q Kᵀ (B, h, T, T)；交叉注意力是 (B, h, T, S)

输入表示

技术做什么关键做法本项目
分词（BPE / WordPiece / SentencePiece）把文本切成子词，控制词表大小，又不会遇到没见过的词从字符开始反复合并最常见的相邻片段— （L12 用字符级）
Token 嵌入把 id 变成 d 维向量查表 E（V × d）；原论文再乘 √d，让嵌入和位置编码尺度相当L14、L15
正弦位置编码告诉模型每个 token 在第几位PE(pos, 2i) = sin(pos / 10000^(2i/d))，奇数维用 cos；不用学，能外推到更长序列—
可学习位置向量同上每个位置一个可训练向量，加在嵌入上（BERT、GPT-2）L15
RoPE 旋转位置编码只关心相对距离按位置把 Q、K 的每对维度旋转一个角度，点积只依赖两者的距离（LLaMA、Qwen 等）—
ALiBi不加位置向量也能分先后给注意力分数加一个与距离成正比的负偏置，越远越小—
权重共享（weight tying）省参数、输入输出用同一套“词义”输出层 Linear 的权重 = 嵌入矩阵的转置—
为什么必须有位置信息注意力只按内容打分，把输入顺序打乱，每个位置的输出只是跟着换位置。第 15 课去掉位置向量后，排序任务的整句准确率从 99.6% 掉到 0%。

注意力

技术做什么关键做法本项目
缩放点积注意力每个位置按相关程度，从所有位置取信息softmax(Q Kᵀ / √d_k + M) VL14、L15
Q / K / V 线性投影同一个输入扮演“提问”“被找”“被取走的内容”三种角色Q = XW_Q，K = XW_K，V = XW_VL14、L15
除以 √d_k防止 softmax 过尖、梯度消失点积方差约为 d_k，除以 √d_k 拉回 1 左右L14
多头注意力同时关注不同方面（语法、指代、位置…）把 d 维切成 h 份各算一次注意力，拼接后乘 W_O；总计算量和单头差不多L15
padding mask让补齐用的空位不参与注意力对应分数加 −∞，softmax 后权重为 0—
因果掩码生成第 t 个词时不能偷看后面上三角位置加 −∞；训练时所有位置仍能并行计算—
交叉注意力解码器“回头看”源句Q 来自解码器，K、V 来自编码器输出L13（加性注意力版本）
自注意力序列内部互相看Q、K、V 都来自同一序列L15

块结构

技术做什么关键做法本项目
残差连接让几十层也能训练，梯度可沿捷径原样回传每个子层都写成 x + Sublayer(x)L11、L15
LayerNorm把每个 token 的特征拉回稳定尺度，不依赖批大小γ · (x − μ) / σ + β，μ、σ 在特征维上算L07（BN）、L09、L15
Post-LN原论文写法LayerNorm(x + Sublayer(x))；深层时依赖 warmup 才稳—
Pre-LN现在的主流写法x + Sublayer(LayerNorm(x))，最后再加一个 LayerNorm；更容易训练深层L15
RMSNorm更省的归一化γ · x / RMS(x)，去掉减均值和 β（T5、LLaMA）L09
逐位置前馈网络 FFN每个位置各自做一次非线性变换，参数大多在这里W₂ φ(W₁x + b₁) + b₂，宽度 d_ff ≈ 4d，所有位置共享权重L02、L15
激活函数提供非线性ReLU（原论文）、GELU（BERT、GPT）L04、L09、L15
SwiGLU门控 FFN，效果更好(Swish(xW₁) ⊙ xV) W₂，d_ff ≈ 8d/3 以保持参数量（PaLM、LLaMA）—
第 15 课的消融结论在 4 层、学习率 0.1 的设置下，去掉残差、去掉 LayerNorm 都会让排序任务整句准确率掉到 1% 以下；FFN 去掉激活函数影响很小，因为 softmax 注意力本身就是非线性的。

输出与损失

技术做什么关键做法本项目
输出线性层 + softmax把每个位置的向量变成词表上的概率logits = h W + b，再 softmaxL01、L09、L15
交叉熵衡量预测分布和真值差多少−log p(真值)，对所有位置取平均L09、L15
Teacher forcing训练时并行算所有位置的损失解码器输入用右移一位的真值，而不是自己上一步的预测L13
Label smoothing防止模型对答案过度自信真值概率设为 1 − ε，其余均分 ε（原论文 ε = 0.1）—

训练

技术做什么关键做法本项目
初始化让每层输出一开始就有合适的尺度权重 ~ N(0, 1/fan_in) 或 Xavier；GPT-2 还会按层数缩小残差分支的初始化L06、L11、L15
Adam / AdamW按每个参数的梯度历史自适应调步长原论文 β₁ = 0.9、β₂ = 0.98、ε = 1e-9；AdamW 把权重衰减和梯度更新分开L09、L15
Warmup + 衰减开头用小步子，避免 Adam 统计量还不准时被推飞原论文 lr = d^(−0.5) · min(step^(−0.5), step · warmup^(−1.5))，warmup 4000 步；现在常用线性 warmup + 余弦衰减L05、L09、L15
Dropout正则化加在嵌入和每个子层输出上，原论文 p = 0.1；还有注意力权重上的 dropoutL08、L09、L15
权重衰减正则化每步把权重乘以 (1 − lr · λ)，通常不对 LayerNorm 和偏置做L08、L09、L15
梯度裁剪防止偶发的大梯度把参数推飞全局梯度范数超过阈值就整体缩小L12、L15
早停与验证集选泛化最好的那一步按验证损失回滚到最好的参数L08、L09、L15
混合精度省显存、加速前向反向用 fp16 / bf16，主权重用 fp32；fp16 要配合 loss scaling— （本项目 GPU 路径用 float32）

推理与效率

技术做什么关键做法本项目
自回归解码一个一个生成把已生成的序列喂回解码器，取下一个位置的分布L12、L13
Greedy / Beam search选输出序列greedy 每步取最大；beam 同时保留 k 条最好的候选（翻译常用 4–5）L13（greedy）
温度 / top-k / top-p 采样让生成更多样logits 除以温度；只在概率最高的 k 个或累计概率 p 以内抽样L12（温度）
KV cache生成时不重复计算历史把每层已算过的 K、V 存起来，新 token 只算自己的 Q、K、V—
MQA / GQA缩小 KV cache多个查询头共用一组（或几组）K、V 头—
FlashAttention省显存、加速长序列分块计算 softmax，不把 T × T 的分数矩阵整个写到显存—
复杂度长序列为什么贵自注意力的时间约 O(T² · d)，显存约 O(T²)；FFN 是 O(T · d²)—

三种架构家族

Encoder-only（BERT、RoBERTa）

只用编码器栈，双向注意力。预训练时遮住部分 token 再预测（MLM）。适合分类、抽取、检索向量。

Decoder-only（GPT、LLaMA）

只用解码器栈，去掉交叉注意力，用因果掩码预测下一个 token。今天的大语言模型几乎都是这种。第 15 课的模型结构上属于编码器栈（没有因果掩码）。

Encoder–decoder（原论文、T5）

编码器读完整个输入，解码器边生成边用交叉注意力回看。适合翻译、摘要。第 13 课的 seq2seq 是同一思路的 RNN 版本。

把第 15 课的模型扩成完整的编码器–解码器，需要补上的只有三样：解码器里的因果掩码、交叉注意力（Q 来自解码器，K、V 来自编码器输出），以及推理时的逐个生成。这三样分别在第 13、14 课里出现过它们的原型。
