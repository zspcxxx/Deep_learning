实验 01 无需 GPU NumPy

单层感知机：一条会移动的直线

感知机是神经网络的祖先。它只会做一件事：在平面上画一条直线，把点分成两边。先把这件事吃透，后面的“多层”“反向传播”才不会像黑盒。

实现 src/dllab/perceptron.py · 入口 lessons/01_perceptron.py

红 / 蓝两类被一条直线分开

这个实验要回答什么

  1. 模型如何根据输入给出 +1 或 -1？
  2. 分错一个点时，权重应该往哪边改？
  3. 为什么 AND、OR 能学会，XOR 怎么学都学不会？

用人话建立直觉

把每个样本看成平面上的点 (x₁, x₂)。感知机保存一组参数：权重向量 w 和偏置 b。对一个点算得分：

s = w₁·x₁ + w₂·x₂ + b

s ≥ 0

模型预测正类 +1

s < 0

模型预测负类 -1

s = 0

全体这样的点连成决策边界（二维时是直线）

关键限制一条直线没法把“对角是一类、另外对角是另一类”的 XOR 切开。这不是学习率没调好，是模型表达能力不够。

预测公式

s = w · x + b
ŷ = +1    若 s ≥ 0
ŷ = -1    若 s < 0

本实验标签也用 +1 / -1（不是 0/1）。这样有一个方便的判错条件：若 y · s ≤ 0，说明标签与得分符号不一致，这个点分错了。

本实验故意留下 XOR 失败，作为进入多层网络的动机

分错了怎么改参数

感知机学习规则：只在分错时更新，分对就跳过。

w ← w + lr · y · x
b ← b + lr · y

含义：把决策边界往“冤枉了这个点”的反方向推一把。学习率 lr 只是步子大小。

收敛定理若数据线性可分（存在某条直线能完美切开），该规则在有限步内会把误分类降到 0。XOR 不满足前提，所以会一直抖、不会收敛。

手算一个小例子

样本 x=(1, 1)，真标签 y=+1，当前 w=(0,0)，b=0，lr=0.1

得分 s
0·1 + 0·1 + 0 = 0 → ŷ=+1？边界上按 ≥0 判正，这里刚好临界
再换一例
若 y=+1 且当前 s=-0.5（判负），则 y·s<0，触发更新
更新后
w ← (0,0) + 0.1·(+1)·(1,1) = (0.1, 0.1)；b ← 0.1
新得分
s' = 0.1+0.1+0.1 = 0.3 > 0，同一个点被“纠正”

代码如何对应

Perceptron.fit 里最核心的几行：

for xi, yi in zip(X, y):
    if yi * (np.dot(self.w, xi) + self.b) <= 0:   # 分错
        self.w += self.lr * yi * xi
        self.b += self.lr * yi

外层再套 epoch：把全部样本扫一遍算一轮。某一轮一个都没分错，就提前停。

数据用截断高斯：在逻辑门四个角附近撒点，但严格裁在小方块内，避免两类重叠。这样 AND/OR 理论上可分，图上又看起来散。

实验脚本做了什么 · 如何运行

  1. 生成 AND、OR、XOR 各约 200 个点，分别训练一个感知机。
  2. 再生成两类中心在对角的二维点，训练第四个模型。
  3. 画出决策边界、每轮误分类数，以及误差曲线对比。
