实验 07 无需 GPU 训练稳定

归一化：把尺度拉回“好学”的区间

特征数量级差几个数量级时，同一组学习率 / 初始化往往学得很慢甚至学不会。输入标准化把特征拉到相近尺度；BatchNorm 在网络内部对每一层的预激活做标准化，让深层训练更稳。本实验用故意拉歪尺度的月牙数据，对比三种设置。

入口 lessons/07_normalization.py · MLP(..., batch_norm=True)

把特征“揉圆”再喂给网络

这个实验要回答什么

  1. 为什么特征尺度差很多时，训练会变难？
  2. 输入标准化（零均值、单位方差）解决了什么？
  3. BatchNorm 和输入标准化有何不同？它放在网络哪一层？

用人话建立直觉

把两个特征想成地图上的东西向：一个以公里计、一个以毫米计。梯度下降沿两个轴走，步长却共用一个学习率——结果往往是一条轴上抖得厉害，另一条几乎不动。归一化就是先统一单位，再学地图。

无归一化

损失下降慢或卡住；决策边界糊；大尺度特征主导更新。

输入标准化

训练前把每个特征减均值除标准差；对表格 / 坐标数据几乎是标配。

BatchNorm

每个 mini-batch（本实验为全批量）上，对隐藏层预激活做标准化，再乘 γ、加 β。

输入标准化

x' = (x − μ) / σ
μ, σ 按训练集每个特征统计

注意：测试时要用训练集上的 μ、σ，不能在测试集上重新估（本实验只在训练集上对比，重点看训练动态）。

Batch Normalization（隐藏层）

ẑ = (z − μ_B) / √(σ_B² + ε)
y = γ ⊙ ẑ + β

本库放在线性层之后、激活之前：Linear → BN → ReLU。γ、β 可学习，避免“标准化后表达能力被锁死”。推理时用训练中滑动平均的均值 / 方差。

和输入标准化的差别输入标准化只做一次、在网络入口；BN 在每一层内部、随训练动态变化，还能减轻 Internal Covariate Shift、允许更大学习率。现代架构里 LayerNorm（按样本而非按 batch）也很常见——本课先把 BN 直觉建立起来。

受控对比实验

固定条件（只改归一化设置）：

  • 数据：Two Moons，再乘尺度 [10, 0.15] 并平移，制造极端量纲
  • 结构：[2, 16, 16, 1]，ReLU，He 初始化，lr=0.35，700 轮
  • 三种设置：无归一化 / 仅输入标准化 / 仅 BatchNorm（原始尺度输入）
实验结论预期无归一化准确率明显偏低；输入标准化与 BatchNorm 都能到高准确率，损失曲线更干净。

实践建议

  • 图像像素常先缩放到 [0,1] 或 ImageNet 均值方差；表格特征优先 StandardScaler / 稳健缩放。
  • BN 对 batch size 敏感：batch 太小时统计不稳，可考虑 GroupNorm / LayerNorm。
  • BN 与 Dropout 同用时注意顺序与模式（train/eval）；推理务必 model.eval()。
  • 本课全批量 SGD 是为了看清效应；真实训练里 BN 几乎总在 mini-batch 上算。
自己改一改把 SCALE 改成 [1, 1]，三种设置差距会缩小——说明归一化的价值在“尺度病态”时最大；或同时打开输入标准化 + BN，观察是否还有增益。
