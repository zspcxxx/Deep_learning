实验 07 需要 PyTorch 可用 GPU

MNIST：把前面的积木接到真实图像

MNIST 是 28×28 灰度手写数字，10 类。本实验用框架完成完整闭环：读数据、定义 MLP 与 CNN、训练、测试集评估、混淆矩阵与误分类可视化。

实现 src/dllab/mnist.py · 入口 lessons/07_mnist.py · 架构图见 architecture.html

这个实验要回答什么

  1. 图像怎样变成模型能吃的张量？
  2. 全连接（MLP）和卷积（CNN）差在哪里？
  3. 训练曲线、混淆矩阵、误分类样本分别告诉你什么？

数据长什么样

规模

训练集 60000 · 测试集 10000 · 10 类（0–9）

像素先 ToTensor 到 [0,1]，再标准化：

x ← (x − 0.1307) / 0.3081

为什么标准化

让输入数量级稳定，Adam 更好走。

仓库若已有 data/MNIST/，不会重复下载。

DataLoader 按 batch 喂给 CPU/GPU。

模型一：MLP（把图当 784 维向量）

Flatten 28×28 → 784
Linear 784→512 → ReLU → Dropout(0.3)
Linear 512→256 → ReLU → Dropout(0.3)
Linear 256→10     # 10 个类别的 logits

它能工作，因为数字相对居中、尺寸固定。缺点：稍微平移、笔画粗细变化，784 维里的“哪一个像素”对不上号，参数也多。Dropout 训练时随机掐断一部分神经元，减轻过拟合。

模型二：CNN（扫描局部笔画）

3×3 卷积核滑动检测局部笔画；MaxPool 降分辨率、保留强响应
Conv 1→32 → ReLU → Conv 32→32 → ReLU → MaxPool(2)  # 28→14
Conv 32→64 → ReLU → Conv 64→64 → ReLU → MaxPool(2)  # 14→7
Flatten 64×7×7 → Linear 128 → ReLU → Dropout → Linear 10
归纳偏置MLP 把空间结构拆掉；CNN 把空间结构当特征来用。同一份 MNIST，CNN 测试准确率通常更高。

训练配方

项目选择为什么
损失CrossEntropyLoss内部含 Softmax；网络最后输出 logits，不要再套 Softmax
优化器Adam，lr=1e-3默认好用的一阶自适应方法
调度每 3 epoch ×0.5后期细调，减少震荡
保存测试准确率创新高写 *_best.pth评估用最佳权重，而非最后一轮

一个训练步就是实验 03 的工业版：loss.backward() 自动反向，optimizer.step() 更新参数。

如何读三种结果图

图正常样子异常时可能意味着
损失/准确率曲线训练和测试一起变好训练准、测试差：过拟合；两者都卡着：学习率或模型太弱
混淆矩阵对角线很亮亮斑在 (4,9)、(3,5) 等：长得像的数字互相认错
误分类样本人看也像写糊了若很工整仍认错：查预处理或标签

如何单独运行

source .venv/bin/activate
# 默认 3 轮、batch 256，够看出 MLP 与 CNN 差距
python scripts/run_lesson.py 07
python scripts/run_lesson.py 07 --epochs 10 --batch-size 128

# 或
python lessons/07_mnist.py --epochs 3 --batch-size 256

有 CUDA 会打印 Using device: cuda。结果在 artifacts/07_mnist/。通过标准（脚本内）：MLP ≥95%，CNN ≥97%（3 epoch 在 GPU 上通常可达）。
