实验 02 无需 GPU 从零实现

多层感知机：把空间折一折再分类

上一节的感知机只有一层，等价于一条直线。MLP 在中间插入隐藏层，先做非线性变换，再分类。XOR 和弯月牙形数据因此变得可解。

实现 src/dllab/mlp.py · 入口 lessons/02_mlp.py

这个实验要回答什么

  1. 隐藏层到底在计算什么？
  2. 为什么必须加激活函数，而不能只堆线性层？
  3. 损失下降和准确率上升，在图上分别长什么样？

用人话建立直觉

XOR 的四团点：左下和右上是类 0，左上和右下是类 1。任何一条直线都会切错两团。

MLP 的办法：先用若干神经元把平面“扭”一下——例如让某一侧被 ReLU 压到 0，另一侧保持——扭完之后，两类在新空间里更容易用最后一层分开。

若没有非线性连续两个线性变换可以合并成一个：(xW₁+b₁)W₂+b₂ = x(W₁W₂)+(b₁W₂+b₂)。层数再多，整体仍是一条直线。非线性是深层网络有意义的前提。

本实验的网络结构

XOR 用 [2, 8, 8, 1]；月牙数据更弯，用更宽的 [2, 16, 16, 1]
隐藏层:  z = a_prev @ W + b
         a = ReLU(z) = max(0, z)

输出层:  z_out = a @ W_out + b_out
         ŷ = sigmoid(z_out) ∈ (0, 1)

输出是“属于类 1 的概率”。标签用 0/1。预测时 ŷ ≥ 0.5 判为 1。

损失：二元交叉熵

L = − mean( y · log(ŷ) + (1−y) · log(1−ŷ) )

真标签是 1 时希望 ŷ 靠近 1；是 0 时靠近 0。代码里加了极小的 eps，避免 log(0)。

参数初始化：ReLU 网络用 He 初始化 W ~ N(0, 2/n_in)；Tanh 用 Xavier。偏置从 0 开始。

训练在做什么

1. Forward

算出每层 z、a，缓存下来给反向用。

2. Loss / Acc

交叉熵 + 阈值准确率。

3. Backward

从 (ŷ−y) 往回传，得到 dW、db。

4. Update

W ← W − lr·dW，b 同理。

输出层用了 Sigmoid + BCE，误差恰好是 ŷ − y（再除以样本数）。隐藏层误差再乘 ReLU 导数：z≤0 处梯度为 0。逐步推导见实验 03。

数据难点期望
XOR 四团噪声点线性不可分训练准确率接近 100%
Two Moons 月牙边界弯曲决策边界跟着月牙弯

看图时注意什么

  • 左图彩色背景是 ŷ 概率，黑虚线是 0.5 等高线；XOR 应出现“对角同色”分区。
  • 中图损失总体下降；右图准确率升到接近 100%。
  • 若损失下降但边界仍乱：轮数不够或学习率过大震荡。
