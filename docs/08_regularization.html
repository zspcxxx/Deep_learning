实验 08 无需 GPU 泛化

正则化：多种手段一起对照

过拟合时训练集（含噪声）背得很熟，测试却掉下去。本课在同一小样本 + 标签噪声设定下，并排验证无正则、L2、L1、Dropout、L1+L2、L2+Dropout、早停、以及过强 L2，看权重大小、稀疏度、训练/测试差距如何变化。

入口 lessons/08_regularization.py · MLP(..., l1=, l2=, dropout=) · 早停用验证集

同一数据，不同约束

这个实验要回答什么

  1. 无正则时过拟合长什么样（train/test gap、||W||）？
  2. L2 压幅度、L1 促稀疏、Dropout / 早停分别改了训练的哪一步？
  3. 正则太强为什么会欠拟合？

用人话建立直觉

把模型想成写作文：字数不限就会堆砌细节（背噪声）；限制字数（L2）、强迫多用短句（L1 稀疏）、随机遮住一半草稿纸再写（Dropout）、写到老师说“够了”就停（早停），都会减少过拟合风险——但限制过头就写不出完整论点。

L1 / L2

L = L_data + (λ₂/2m) Σ||W||² + (λ₁/m) Σ|W|
∂L/∂W ← ∂L_data/∂W + (λ₂/m) W + (λ₁/m) sign(W)

L2 倾向把权重均匀压小；L1 的次梯度含 sign(W)，更容易把权重推到精确的 0。代码：MLP(..., l1=0.04, l2=0.15)。

Dropout 与早停

Dropout：训练时按概率 p 将隐藏激活置零（inverted dropout）；predict 时关闭。接口 dropout=0.4。

早停：另留验证集，监控验证 BCE；连续 patience 轮无提升则停止，并恢复验证最优权重。fit(..., X_val=, y_val=, early_stop_patience=80)。

受控对比实验

  • 数据：Two Moons，噪声 0.32；训练 28 点（翻转 8 个标签）；验证 60；其余测试
  • 结构：[2, 64, 64, 1]，ReLU，He，lr=0.5，最多 1600 轮
  • 八种设置如上表，其它条件固定
通过标准（脚本内）无正则高 train + 大 gap；L2 缩小 ||W||；L1 稀疏度明显高于 none；过强 L2 欠拟合；早停提前结束；Dropout / 组合方法权重或训练表现符合约束。

实践建议

  • 先做出明显过拟合，再加正则，否则分不清“太强”还是“没学会”。
  • 表格数据常用 L2 / weight decay；大网络常用 Dropout / DropPath；都要配合验证集调强度。
  • 早停几乎零成本，应作为默认习惯；最终报告用验证选出的模型在测试集上只评估一次。
  • 数据增强与更多干净数据，往往比死拧 λ 更有效。
自己改一改改 SETUPS 里的 λ / dropout；把 N_FLIP 设为 0 看差距是否缩小；或把早停 patience 调大，观察停得更晚时 test 如何变化。
