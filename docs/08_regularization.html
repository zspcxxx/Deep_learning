实验 08 无需 GPU 泛化

正则化：别把噪声也学进去

模型太“自由”时，会把训练集里的标签噪声和偶然起伏一并记住，训练集准确率虚高、测试集掉下去——这叫过拟合。正则化给参数加约束：适量 L2 让权重变小、边界更平滑；过强则会欠拟合。本实验用小样本 + 故意翻转的标签，把三种结局画出来。

入口 lessons/08_regularization.py · MLP(..., l2=..., dropout=...)

容量太大 / 刚好 / 被勒太紧

这个实验要回答什么

  1. 过拟合长什么样？为什么训练准确率高不等于泛化好？
  2. L2 正则如何进入损失与梯度？它如何改变 ||W||？
  3. 正则太强时会发生什么？

用人话建立直觉

考试前把练习册答案背下来，遇到换题就懵——模型也会这样。正则化像限制“背诵细节”的自由度：偏好更简单的解（更小的权重、更平滑的边界）。

无正则

训练集（含噪声标签）几乎记满；权重大；决策边界弯绕；训练≫测试。

适量 L2

权重被压小；边界更顺；仍能学到主结构。

过强 L2

权重几乎被压成 0；学不动，训练/测试都差 → 欠拟合。

L2 权重衰减

L = L_data + (λ/2m) Σ ||W||²
∂L/∂W ← ∂L_data/∂W + (λ/m) W

等价于每次更新把权重往 0 拉一点（weight decay）。偏置通常不衰减；本实现只正则化 W。代码：MLP(..., l2=0.15)。

Dropout（库已支持）

训练时随机将隐藏单元置零（本库用 inverted dropout，推理时不改尺度）。全批量小数据上效果不如 L2 直观，故本实验主对比 L2 强度；可自行改 dropout=0.3 观察。接口：MLP(..., dropout=0.3)。

受控对比实验

  • 数据：Two Moons，噪声 0.32；只用 28 个训练点，并翻转 8 个训练标签
  • 结构：[2, 64, 64, 1]，ReLU，He，lr=0.5，1600 轮
  • 三种 l2：0（无）/ 0.15（适量）/ 2.0（过强）
实验结论预期无正则训练准确率很高、权重很大、训练-测试差距大；适量 L2 明显缩小 ||W||；过强 L2 训练准确率垮掉（欠拟合）。

实践建议

  • 先保证模型能过拟合训练集，再加正则——否则分不清是正则太强还是模型太弱。
  • L2 / weight decay 与学习率、批量大小联动；现代优化器里 AdamW 把 decay 解耦得更干净。
  • Dropout 多用于较大网络与 mini-batch；推理务必关闭（本库 predict 已关闭）。
  • 数据增强、早停、更多数据往往比死拧 λ 更有效。
