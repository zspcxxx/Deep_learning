循环神经网络：让网络记住过去

前面的网络一次看完整个输入。文字、语音、股价这类数据是按时间一个个到来的，网络需要一边读一边“记住”前面的内容。 本课手写 RNN、LSTM 和 GRU 的随时间反向传播，看普通 RNN 为什么记不住 40 步以前的事、LSTM 和 GRU 的门怎么解决它，最后训练一个会自己编英文名字的模型。

入口 lessons/12_rnn.py · 实现 src/dllab/rnn.py（RNNCell / LSTMCell / GRUCell / RecurrentNet / gradient_check）

按时间展开的 RNN

这个实验要回答什么

  1. RNN 怎么在时间上共享权重？反向传播怎么“沿时间”往回传？
  2. 普通 RNN 能记住多远以前的信息？为什么记不住？
  3. LSTM 的遗忘门、输入门、输出门和细胞状态各起什么作用？遗忘门的初始化为什么重要？
  4. GRU 怎么用更新门和重置门做到类似的事？更新门偏置为什么要设大？
  5. 一个按字符预测的小模型，能不能学会“编”出像样的新名字？

RNN：带记忆的网络

h_t = tanh(x_t · Wx + h_{t-1} · Wh + b)        h_0 = 0
y_t = h_t · Wy + by                              （需要输出的那些时间步）

隐藏状态 h_t 是网络的“记忆”：它由当前输入 x_t 和上一步的记忆 h_{t-1} 共同决定。不管序列多长，每一步用的都是同一组 Wx、Wh、b—— 这和 CNN 在空间上共享卷积核是同一个思路，只不过 RNN 是在时间上共享。

随时间反向传播（BPTT）

把 RNN 沿时间展开，就是一个很深的前馈网络（每个时间步一层），只是各层共享权重。反向传播从最后一步开始往前走：

da_t     = (dL/dh_t + dh_next) ⊙ (1 − h_t²)        （tanh 的导数）
dWx     += x_tᵀ · da_t       dWh += h_{t-1}ᵀ · da_t       （每一步的贡献累加）
dh_next  = da_t · Whᵀ                                      （传给上一步）

代码在 RNNCell.backward 里，不到 15 行。实验开头用数值梯度对 RNN、LSTM、GRU 三种单元、两种用法做了检查，误差都在 1e-6 以下。

RNN 训练时梯度偶尔会突然变得很大，所以训练循环里做了梯度裁剪：所有梯度的总范数超过阈值时，按比例缩小到阈值。

梯度沿时间消失

第 1 步的输入要影响最后的损失，梯度得从第 T 步一路传回第 1 步，中间每一步都要乘一次 diag(1 − h²) · Whᵀ。 tanh 的导数不超过 1，几十次连乘后梯度通常指数级变小——和第 04、11 课的深层网络梯度消失是同一件事，只不过“层”换成了“时间步”。

实验里测到：训练前，延迟 40 步时 RNN 第 1 步输入收到的梯度只有最后一步的 1.3e-5。网络根本“感觉不到”第 1 个符号对结果有影响，自然学不会去记它。

LSTM：用门控制记忆

[i, f, o, g] = [σ, σ, σ, tanh](x_t · Wx + h_{t-1} · Wh + b)
c_t = f ⊙ c_{t-1} + i ⊙ g          细胞状态：加法更新
h_t = o ⊙ tanh(c_t)
门作用
遗忘门 f旧记忆 c_{t-1} 保留多少（1 = 全部保留）
输入门 i新内容 g 写入多少（0 = 忽略当前输入）
输出门 o记忆里有多少拿出来给 h_t 用

关键在细胞状态的加法更新：沿 c 往回传梯度时，每步只乘遗忘门 f。f 接近 1 时梯度几乎原样通过——这和第 11 课残差连接 h + F(h) 是同一个思路。

遗忘门偏置常见的默认值是 1，此时 f ≈ sigmoid(1) ≈ 0.73，40 步后梯度只剩 0.73⁴⁰ ≈ 3e-6，LSTM 一样学不会。 本课把遗忘门偏置初始化为 3（f ≈ 0.95），细胞一开始就倾向于保留记忆——和第 11 课“让残差块从恒等映射起步”是同一个道理。

GRU：两个门就够了

GRU（Gated Recurrent Unit）没有单独的细胞状态，隐藏状态自己就是记忆。它用更新门 z 决定“保留旧状态还是换成新内容”，用重置门 r 决定写新内容时要不要看旧状态：

z = σ(x_t · Wxz + h_{t-1} · Whz + bz)                 更新门
r = σ(x_t · Wxr + h_{t-1} · Whr + br)                 重置门
n = tanh(x_t · Wxn + r ⊙ (h_{t-1} · Whn + bn))        候选记忆
h_t = (1 − z) ⊙ n + z ⊙ h_{t-1}
门作用
更新门 z旧状态保留多少（1 = 原样复制 h_{t-1}，对应 LSTM 里接近 1 的遗忘门）
重置门 r计算候选记忆 n 时看多少旧状态（0 = 当这一步是新的开始）

沿 h 往回传时，复制路径每步只乘 z。z 接近 1，梯度就能穿过几十步——和 LSTM 细胞状态上乘遗忘门是同一件事，只是 GRU 把“细胞”和“隐藏状态”合成了一个向量，参数大约是同宽度 LSTM 的 3/4。

更新门偏置和遗忘门偏置是同一类初始化。偏置为 0 时 z ≈ 0.5，40 步后复制路径只剩 0.5⁴⁰ ≈ 9e-13，GRU 记不住开头。 本课把更新门偏置初始化为 3（z ≈ 0.95），一开始就倾向于保留旧状态。代码在 GRUCell，候选记忆把偏置放在重置门里面（和 PyTorch 的 GRU 一致）。

实验一：记住第 1 个符号

  • 输入：长度为“延迟”的随机符号序列（4 种符号，one-hot）；读完后输出第 1 个符号。后面的符号和第 1 个来自同一个字母表，所以必须记住开头、同时忽略长得一样的干扰。随机猜对的概率是 25%。
  • 模型：隐藏层 32 维的 RNN、LSTM 和 GRU，只在最后一步接输出层。
  • 训练：Adam（lr 3e-3，余弦衰减），1500 步，每步 64 条现场生成的新序列，梯度范数裁剪到 1。测试集 1000 条，缓存在 data/12_rnn/。
  • 延迟 5 / 10 / 20 / 40 步。另外在 40 步时测两个对照：遗忘门偏置为 1 的 LSTM，以及更新门偏置为 0 的 GRU。

实验二：生成名字

  • 数据：3.2 万个英文名（karpathy/makemore 的 names.txt，MIT 许可），已随仓库放在 data/names/。训练 28000 个，验证 4033 个。
  • 每个名字前后各加一个 .：输入 .emma，目标 emma.。每一步都预测下一个字符（27 个字符，交叉熵），补齐的位置用掩码排除。
  • 生成：从 . 开始，每一步按 softmax(logits / T) 抽一个字符，再把它当作下一步的输入，直到抽到 .。温度 T 越低越保守，越高越“敢想”。

Jetson（192.168.0.110）实测，固定随机种子。GRU 在 T = 1.0 时编出的名字例如：arisya、alissa、evant、lykes、kiriah、kaynel。

自己改一改

  • 把 DELAYS 加上 80，看 LSTM（偏置 3）和 GRU（更新门偏置 3）还能不能记住；再把 FORGET_BIAS 或 UPDATE_BIAS 改成 5 试试。
  • 去掉梯度裁剪（clip=0），观察 RNN 训练时的梯度范数 model.grad_norm_ 会不会出现尖峰。
  • 把 data/names/names.txt 换成你自己的单词表（每行一个，小写字母），让模型编别的东西。
