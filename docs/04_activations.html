激活函数：网络里的“弯折”

线性层只会旋转、拉伸、平移空间。激活函数在每个神经元上弯折一次，网络才能拟合曲线。不同弯折方式还决定训练能不能进行下去。

平滑饱和 vs 分段线性

这个实验要回答什么

  1. 常见激活长什么样、导数长什么样？
  2. Softmax 如何把一组分数变成概率？温度 T 有什么用？
  3. 为什么深层网络里 Sigmoid 容易梯度消失，而 ReLU 好得多？

用人话建立直觉

每个隐藏神经元先算线性分 z = w·x + b，再经过 a = f(z) 才送给下一层。反向传播时，误差要乘上 f'(z)。

梯度消失若 |f'(z)| 经常远小于 1（Sigmoid 最大也只有 0.25），层层相乘会指数衰减，前面的层几乎改不动。

ReLU 在 z>0 时导数是 1，正半轴上梯度可以原样传回去，所以深度网络默认从 ReLU 家族开始选。

按家族理解，不必背所有公式

家族代表直觉代价
S 形Sigmoid, Tanh压到有限区间，适合概率或门控两端饱和，梯度≈0
分段线性ReLU, Leaky ReLU负的掐掉或留一小坡ReLU 可能“死亡”
平滑新秀GELU, SiLU, Mish负半轴不是硬切；Transformer 常用 GELU计算稍重
硬近似HardSwish, HardSigmoid折线换速度，方便移动端精度换速度
输出专用Softmax多类互斥概率，和为 1一般只放最后一层

几条真正会写进代码的公式

Sigmoid(z) = 1 / (1 + e^{−z})
Sigmoid'(z) = s(1−s)                 # 最大 0.25

ReLU(z) = max(0, z)
ReLU'(z) = 1 (z>0) else 0

GELU(z) ≈ 0.5 z (1 + tanh(√(2/π)(z + 0.044715 z³)))

Softmax(z)_i = exp(z_i − max z) / Σ_j exp(z_j − max z)

Softmax 先减最大值是为了数值稳定。温度 T 就是用 z/T：T 小更“独断”（接近 one-hot），T 大更平均。

怎么选用（实用口诀）

场景建议
隐藏层默认ReLU；不稳或死神经元再试 Leaky ReLU / GELU
二分类输出Sigmoid + BCE
多分类输出Softmax + 交叉熵（框架里常合并进 CrossEntropyLoss）
回归输出常常直接线性（Linear）
不要做的事不要在隐藏层乱堆 Softmax，通道会被强迫互斥
