实验 03 手算 + 训练 梯度检查

反向传播：误差如何一层层传回去

训练神经网络 = 求损失对每个权重的导数，再沿导数反方向改一点点。反向传播用链式法则高效完成这件事，避免对每个权重逐个做数值扰动。

实现 src/dllab/backprop.py · 入口见文末两个脚本

这个实验要回答什么

  1. 前向时要记住哪些中间量？
  2. 输出层的误差为什么经常是 ŷ − y？
  3. 怎么证明手写梯度没有写错？（梯度检查）

用人话建立直觉

把网络看成流水线：原料 x 经过“加权 + 激活”变成 ŷ，再变成损失 L。某个螺丝（权重）拧紧一点，L 会变大还是变小？这个变化率就是梯度。

每一步只乘一个局部导数，整条链连起来就是 ∂L/∂W

前向（必须缓存）

z1 = X @ W1 + b1
a1 = σ(z1)            # 或 ReLU
z2 = a1 @ W2 + b2
a2 = σ(z2)            # ŷ，形状 (N, 1)

forward() 把 z1, a1, z2, a2 放进字典。反向要用 z（算激活导数）和 a（当下一层的输入）。

反向：从输出往回

对 BCE + 输出 Sigmoid，有一个被广泛使用的化简：

dz2 = (a2 − y) / N          # N 是样本数，对应 mean

dW2 = a1.T @ dz2
db2 = sum(dz2, axis=0)

da1 = dz2 @ W2.T
dz1 = da1 * σ'(z1)          # Sigmoid: σ'(z)=σ(z)(1−σ(z))
dW1 = X.T @ dz1
db1 = sum(dz1, axis=0)

然后 W ← W − lr · dW。

形状口诀误差从右边往左边流；权重梯度 =「流入这层的激活」转置 ×「这层的误差」。对照 BackpropNN.backward 读一遍就会对上。

单样本直觉（与 03-visual 脚本一致）

固定 x=[0.5, 0.8]，y=1，网络 2→2→1。前向得到 a2≈0.70，则

dz2 = a2 − y ≈ 0.70 − 1 = −0.30

负号表示：输出偏小，应增大指向正类的权重。随后 dW2 = a1ᵀ · dz2，再把误差经 W2ᵀ 传回隐藏层。

梯度检查：用定义核对实现

数值梯度 ≈ [L(w+ε) − L(w−ε)] / (2ε)

和反向传播得到的解析梯度比相对误差。本实验阈值是 < 1e-6。通过了，才说明 backward 没有写反、没有漏除 N、没有用错激活导数。

注意检查时要用很小的网络和很小的 batch——每个参数都要前向两次。代码在 gradient_check()。

看图与日志时注意什么

  • 梯度检查失败：优先查有没有漏除样本数、激活导数是否作用在 z 上、BCE 是否和 Sigmoid 配错。
  • 可视化图里输出层梯度范数通常大于隐藏层——误差往回传会被激活导数缩小，这和实验 04 梯度消失是同一件事的萌芽。
  • 故意把 dz2 改成不除以 m，看相对误差炸到什么程度——这是最好的调试练习。
