实验 11 纯 NumPy，约 35 秒 深度网络的关键结构

残差连接：让 50 层网络也能训练

网络越深表达能力越强，可普通网络加深到一定程度后，连训练集都拟合不了。2015 年的 ResNet 给每个块加了一条“捷径”： 输出 = 输入 + 块的计算结果。这一个加号让网络可以堆到上百层，今天的 CNN、Transformer 里到处都是它。

入口 lessons/11_residual.py · 实现 src/dllab/nn.py（Residual 层）、src/dllab/resnet.py（build_deep_mlp）

一个残差块

这个实验要回答什么

  1. 普通全连接网络加深到多少层会开始“学不动”？学不动是过拟合还是优化问题？
  2. 给每个块加一条 h + F(h) 的捷径之后，同样的层数、同样的参数，结果差多少？
  3. 从信号传播的角度看，捷径到底改变了什么？
  4. 为什么残差分支的最后一层要初始化为 0？

退化问题

假设一个 18 层网络已经训练得很好。在它后面再加 32 层，只要这 32 层什么都不做（恒等映射），50 层网络至少和 18 层一样好。 所以从“能表示什么”看，更深不可能更差。

但实验里，普通网络 50 层时连训练集都分不对——训练准确率掉到 33%，和随机猜一样。这不是过拟合（过拟合是训练好、测试差）， 而是优化失败：梯度下降找不到那组“什么都不做”的参数。让一叠 ReLU + Dense 层精确地学成恒等映射，其实非常难。

残差连接

既然恒等映射难学，那就让它成为默认值：每个块只学“在输入基础上改多少”。

普通块    h ← F(h)
残差块    h ← h + F(h)          F(h) = W2 · ReLU(W1 · ReLU(h) + b1) + b2

如果某一块没什么用，F 只要学成 0 就行——把权重推向 0 比学成恒等映射容易得多。F 学的是“残差”，即在恒等映射之上的修正量。

代码里 Residual 层把若干子层包起来：前向 return x + F(x)；反向 return dout + F.backward(dout)。整个实现就这么几行。

为什么梯度能传下去

普通网络   ∂L/∂h₁ = ∂L/∂h_L · ∂F_L/∂h · … · ∂F_1/∂h          （L 个雅可比矩阵连乘）
残差网络   ∂(h + F(h))/∂h = I + ∂F/∂h
           ∂L/∂h₁ = ∂L/∂h_L · (I + ∂F_L/∂h) · … · (I + ∂F_1/∂h)

普通网络里，梯度要穿过每一层的雅可比矩阵，连乘几十次后很容易衰减（或爆炸）。残差网络把乘积展开后有一项就是 I·I·…·I = I： 不管中间的 F 怎样，总有一份梯度原封不动地从输出传回输入。实验里测到，训练前 50 层普通网络第 1 块收到的梯度只有最后一块的约 1/19， 而残差网络每一块完全一样。

分支为什么要零初始化

如果残差分支 F 一开始就输出和 h 同样大小的随机信号，h + F(h) 每经过一块方差就大约翻倍。24 块下来，隐藏状态的标准差从 0.54 涨到了 1800 以上， 训练很不稳定，50 层时只有 81% 的训练准确率。

把每个分支最后一个 Dense 的权重初始化为 0，F(h) 一开始恒为 0，每块都是 h + 0 = h：整个网络起步时相当于一个只有首尾两层的浅网络， 信号和梯度都能原样通过；训练过程中各块再逐渐学会自己的修正量。实际的 ResNet 把每块最后一个 BatchNorm 的 γ 初始化为 0， GPT 等 Transformer 按层数缩小残差分支的初始权重，思路相同。

代价零初始化的分支一开始“什么都不做”，前几十轮损失下降得比较慢；只有 2 个块的浅网络上，残差网络在 100 轮内反而比普通网络略差。残差连接解决的是“深”的问题。

对比实验

  • 数据：三条螺旋臂，各 300 个训练点，每条绕 2.5 圈，另取 900 个点做测试。缓存在 data/11_residual/。
  • 网络：宽度 32；stem Dense(2→32) → 若干个块 → ReLU → Dense(32→3)。深度按 Dense 层数计：6 / 10 / 18 / 34 / 50 层（2 / 4 / 8 / 16 / 24 个块）。
  • 三种网络：plain（普通）、residual（残差 + 分支末层零初始化）、residual_he（残差 + 分支 He 初始化）。同一深度下三者参数完全相同。
  • 训练：AdamW，lr 2e-3（Warmup 2 轮 + Cosine），batch 64，100 轮；不加权重衰减、不早停——只比较“能不能把训练集拟合好”。
  • 额外诊断：训练前，在 50 层网络上测每块输出的标准差（前向信号）和传到每块的梯度 ‖dL/dh‖（反向信号）。
