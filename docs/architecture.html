④ CNN 模型结构

卷积神经网络由两个卷积块 + 一个全连接分类头组成， 总计约 46 万参数。

输入 Input
输入图像 (batch, 1, 28, 28)
Block 1 · 特征提取
Conv2d(1 → 32, 3×3, pad=1) 32 × 28 × 28
ReLU 激活
Conv2d(32 → 32, 3×3, pad=1) 32 × 28 × 28
ReLU 激活
MaxPool2d(2) 32 × 14 × 14
Dropout(0.25) 正则化
Block 2 · 深层特征
Conv2d(32 → 64, 3×3, pad=1) 64 × 14 × 14
ReLU 激活
Conv2d(64 → 64, 3×3, pad=1) 64 × 14 × 14
ReLU 激活
MaxPool2d(2) 64 × 7 × 7
Dropout(0.25) 正则化
Classifier · 分类头
Flatten 3136 = 64 × 7 × 7
Linear(3136 → 128) 128
ReLU 激活
Dropout(0.5) 正则化
Linear(128 → 10) 10 类 logits
🎯 CrossEntropyLoss
内部含 LogSoftmax

⑪ 架构总结

一句话概括整个程序的架构设计。

数据层（加载 → 标准化 → DataLoader） → 模型层（MLP / CNN） → 训练层（前向 → 损失 → 反向 → 更新 → 评估 → 保存） → 可视化层（样本 / 曲线 / 混淆矩阵 / 误分类）。
层次 主要函数 / 类 职责
数据层get_data_loaders()加载、标准化、批量封装
模型层MLP / CNN定义网络结构与前向传播
训练层train() / evaluate()训练循环、评估、保存最佳模型
可视化层plot_*()样本、曲线、混淆矩阵、误分类
入口main()串联四个层次，输出最终结果
