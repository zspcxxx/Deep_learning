实验 09 无需 GPU 串课实战

综合实战：把 01–08 串成一次训练

前面每课只拧一颗螺丝。这一课用同一份“有点别扭”的数据，训练一个更深的 MLP：一条故意踩坑的 naive 流水线，一条把学习率、初始化、归一化、正则与早停装齐的 tuned 流水线。看测试集差距，就是前面知识有没有真正接上。

入口 lessons/09_full_pipeline.py · 复用 src/dllab/mlp.py 全部开关

tuned 流水线积木

这个实验要回答什么

  1. 一次完整训练里，前面各课的“旋钮”分别拧在哪？
  2. 为什么 naive（坏 lr / 坏 init / 无归一化 / 无正则）会学崩或学不好？
  3. tuned 流水线能否在同一数据上拿到明显更高的测试准确率？

知识清单（对照前面课程）

课用在本实验哪里
02 / 04多层感知机 + ReLU 隐藏层
03反向传播、全批量 SGD 更新
05tuned：lr=0.4；naive：lr=6.0（过大）
06tuned：He；naive：large 高斯
07tuned：输入标准化 + BatchNorm；naive：原始极端尺度
08tuned：L2 + Dropout + 验证集早停；naive：无正则、跑满轮数

两条流水线

naive

large 初始化、过大学习率、不标准化、无 BN / L2 / Dropout / 早停。用来复现“没串课”时的惨状。

tuned

He + lr=0.4 + 标准化 + BN + L2=0.06 + Dropout=0.25 + patience=100。把 05–08 的结论一次装上。

数据设定

  • Two Moons，噪声 0.22，再乘尺度 [12, 0.12] 并平移（制造量纲问题）
  • 训练 80（其中翻转 6 个标签）/ 验证 80 / 其余测试
  • 网络 [2, 32, 32, 32, 1]，最多 1200 轮
通过标准tuned 测试准确率 ≥85%，且比 naive 高出至少 15 个百分点（naive 学崩或明显更差也算）。
