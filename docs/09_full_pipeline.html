实验 09 MNIST 手写数字识别 11 项核心技术全景

综合实战：集齐 11 项核心技术识别 MNIST 手写数字

前面每课拆解了一个独立环节。本节作为收官实战，在经典的 MNIST 手写数字识别（28×28 灰度图，0–9 十分类）任务上，将参数初始化、激活函数、Dropout、归一化（BN / LN / RMSNorm）、损失函数（MSE / Cross-Entropy）、L1/L2 正则化、反向传播、优化器（SGD+Momentum / AdamW）、学习率调度（Warmup + Cosine）、权重衰减、Early Stopping 全部组装进同一个纯 NumPy 深度网络。

MNIST 现代训练流水线全貌

这个实验要回答什么

  1. 深度学习的 11 个核心环节分别解决什么问题？如何在一个真实图像多分类任务里协同工作？
  2. 为什么用 Large Init + Sigmoid + MSE + 固定步长 SGD（naive）在深层手写数字识别上收敛极慢、精度低下？
  3. 换上 He/Xavier + GELU/ReLU + RMSNorm/BN + Cross-Entropy + AdamW/Momentum + WarmupCosine + 解耦权重衰减 + Early Stopping 后，测试集准确率与收敛速度提升多少？

核心技术公式与实现要点

  • 归一化（BN / LN / RMSNorm）：
    • BatchNorm：按 batch 维求均值方差，推理时用滑动平均统计量。
    • LayerNorm：按样本特征维标准化，不依赖 batch 大小。
    • RMSNorm：省去均值中心化，仅按均方根缩放 \(\hat{z} = \frac{z}{\sqrt{\frac{1}{d}\sum z_i^2 + \epsilon}}\)，现代大模型与深层网络常用。
  • 损失函数（Cross-Entropy vs MSE）：配合 Softmax 输出概率 \(p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}\)，交叉熵损失 \(L = -\frac{1}{m}\sum \log p_{y_i}\) 对 logits 的梯度直接简化为 \(\frac{1}{m}(p - y_{\text{onehot}})\)，误差越大梯度越强，不会像 Sigmoid+MSE 那样在饱和区梯度消失。
  • 优化器与解耦权重衰减（AdamW vs SGD+Momentum）：AdamW 在更新一阶动量 \(m_t\) 和二阶动量 \(v_t\) 之前，先执行解耦权重衰减 \(W \leftarrow (1 - \eta_t \lambda_{\text{wd}})W\)，避免 L2 正则项被自适应梯度平方根缩放稀释。
  • 学习率调度（Warmup + Cosine）：前 warmup_epochs 轮从 0 线性升温至峰值学习率（防止训练初期统计量未稳时梯度爆炸），随后按余弦曲线平滑退火至 min_lr。

三条对比流水线

1. naive（反面教材）

large 初始化 + Sigmoid + 无归一化 + MSE 损失 + 固定学习率 SGD，无正则与早停。梯度饱和且信号失衡，准确率停留在很低水平。

2. momentum_bn（经典进阶）

输入标准化 + He 初始化 + ReLU + BatchNorm + Cross-Entropy + SGD+Momentum + Warmup+Cosine + L1/L2 + Dropout + 早停。

3. tuned（现代全套配置）

输入标准化 + He/Xavier + GELU + RMSNorm + Cross-Entropy + AdamW（含解耦权重衰减）+ Warmup+Cosine + Dropout/L2 + 早停。

MNIST 数据设定与网络结构

  • 数据集：MNIST 手写数字（\(28 \times 28 = 784\) 维特征，类别 \(0\text{–}9\)）。数据文件 data/mnist/mnist.npz 已随仓库提供，离线即可运行（文件缺失时自动下载并校验；完全无网又没有该文件时，启用内置 28×28 手写笔画生成器兜底）。
  • 划分：训练集 4000 张 / 验证集 800 张 / 测试集 1200 张。
  • 网络结构：[784, 128, 64, 10]（两层隐藏层 + 10 分类输出头），Mini-batch 大小 128，训练最多 35 个 Epoch。
通过标准tuned 与 momentum_bn 数值稳定（无 NaN），tuned 测试集准确率 \(\ge 90\%\)（通常可达 \(94\%\sim 96\%\)），且显著领先 naive 至少 25 个百分点。
