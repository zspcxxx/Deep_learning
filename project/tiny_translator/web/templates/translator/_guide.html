参数含义与作用详解

按配置页上的三组参数，逐项说明含义、默认值、改了会发生什么。 可与左侧「配置」对照阅读；调完参数后切回配置页点「检查配置」或「开始训练」。

这个实验在做什么

任务是英→中机器翻译：给定一句英文，生成一句中文。模型是手写的小型 Transformer（正弦位置编码、 缩放点积多头注意力、Pre-LN / Post-LN、因果掩码、可选共享输出层），反向传播由 PyTorch autograd 完成， 没有调用 nn.Transformer。

输入

英文按词和标点切分；中文按字切分（可选统一为简体）。

模型

编码器读英文，解码器自回归生成中文；交叉注意力对齐源端每个词。

目标

最小化带标签平滑的交叉熵；用字级 BLEU 衡量译文质量。

产出

runs/<时间>_<名称>/ 下保存配置、词表、曲线、best/last 权重。

建议用法先点预设「快速试跑」跑通一遍，再对照本页改一两个参数做对比实验； 不要一次改十几个旋钮。

网页上的三步

  1. 配置：下载数据集；调数据 / 结构 / 训练参数，或套用预设；「检查配置」会真实读数据、建词表和模型，给出句对数、词表大小、参数量和总步数。
  2. 训练：后台线程训练；页面显示进度、损失 / BLEU / 学习率曲线、每轮样例、日志和 GPU 使用率；可随时停止（停止时保存当前权重）。
  3. 验证：选已完成的运行；交互翻译（贪心或束搜索）并看交叉注意力热力图；在测试集或验证集上批量算 BLEU。

一、数据参数

控制「用多少语料、怎么切分、词表多大、留多少给验证和测试」。改这一组通常比改模型结构更划算：数据质量决定上限。

运行名称 name（默认 demo）

只影响目录名：结果写到 project/tiny_translator/runs/<时间戳>_<名称>/。起一个能区分实验的名字 （如 quick、d256_ep30），方便验证页对照。

数据集 dataset（默认 cmn-eng）

对应 data/<名称>.tsv，每行 英文<Tab>中文。内置 cmn-eng 来自 manythings.org 整理的 Tatoeba 英中句对（约 3.2 万对，CC-BY 2.0）， 首次训练或点「下载」时自动拉取。也可自备同格式的 TSV，刷新后会出现在下拉框。

注意Tatoeba 句子偏短、口语化。常见短句容易译对；长句、罕见专名、训练集没见过的说法容易错 （英文稀有词常变成 <unk>）。这是小数据上的正常现象，不是实现写错了。

最多使用句对数 max_pairs（默认 0 = 全部）

从文件里最多取多少对再划分训练/验证/测试。先设 3000–5000 做烟雾测试能很快看到曲线是否正常；正式对比再用全部。

作用：缩小语料 → 训练更快、词表更小、上限更低；设为 0 → 用满文件（长度过滤后约 3.2 万对）。

中文统一为简体 zh_simplified（默认开启）

Tatoeba 中文繁简混杂。开启后用 zhconv 转成简体再按字建词表。

  • 开：字表更小、同一意思不会拆成繁简两套字，BLEU 更可比（推荐）。
  • 关：保留原文繁简；词表变大，同义字被当成不同符号，一般更难学。

英文最大词数 max_src_len（默认 20）

英文分词后超过此长度的句对直接丢弃。短上限 → 丢掉长句、训练更快、位置编码覆盖的范围更小； 过大 → 保留长句，但批内 padding 变多，显存和每步时间上升。

本实验默认语料大多很短（平均约 7 个英文词），20 已经够用。若换成自己的长句语料，再按分布调高。

中文最大字数 max_tgt_len（默认 30）

两层含义：

  1. 训练时：超过此长度的句对丢弃；
  2. 推理时：解码器最多生成这么多字（再加起止符），太短会截断译文。

默认中文平均约 10 字，30 留有余量。生成总爱「说不完」时，可略增；想强制短答可略减。

词表最低频次 min_freq（默认 2）

只在训练集上统计：出现次数 < 此值的英文词 / 中文字记为 <unk>。

  • 提高（如 3–5）：词表更小、更稳，但更多词变成未知，专名更容易糊。
  • 降到 1：几乎保留所有符号，参数里嵌入变大，稀有词仍可能学不好。

验证页会标出源端未登录词（红色）。若大量句子带红标，优先考虑加数据或调低 min_freq，而不是盲目加大模型。

验证集比例 val_ratio（默认 0.05）

打乱后切出的验证集占比。每轮结束在其上算验证损失和字级 BLEU，用来选 best.pt、画曲线、触发早停。

太小 → BLEU 噪声大，早停不稳；太大 → 训练集变少。默认 5%（约 1600 句）对 3 万对语料较合适。 与测试集合计必须 < 50%。

测试集比例 test_ratio（默认 0.05）

测试集训练全程不参与：不用于选模型，只在训练结束和验证页评估时使用。用来回答「没见过的句子上大概怎样」。 不要根据测试集反复调参，否则它就变成第二个验证集。

二、模型结构参数

决定容量与计算量。参数量大致随 d_model² · (层数) 和词表大小增长；「检查配置」会给出精确参数量。

模型宽度 d_model（默认 256）

词向量维度，也是每一层隐藏状态的宽度。注意力、残差、前馈的输入输出都围绕它。

  • 必须能被 n_heads 整除（每个头的维度 = d_model / n_heads）。
  • 增大 → 表达力更强、显存与时间上升；过小（如 64）在完整语料上容易欠拟合。
  • 快速试跑用 128；标准 256；加大预设 384。

注意力头数 n_heads（默认 4）

多头注意力把表示拆成若干子空间并行做「按键查值」（第 14 课）。头数多 ≠ 一定更好：总宽度固定时， 头越多每个头越窄。常见搭配：128/4、256/4、384/6。

交叉注意力热力图是各头平均后的结果，用来观察「生成某个中文字时在看哪些英文词」。

编码器层数 n_enc_layers（默认 3）

英文自注意力 + 前馈堆叠的层数。更深 → 更能刻画源句结构，也更贵、更容易过拟合小数据。 本实验 2–4 层通常够用；小数据优先加宽或加数据，而不是无脑加到 8+ 层。

解码器层数 n_dec_layers（默认 3）

每层含：因果自注意力（只看已生成的中文）→ 交叉注意力（看英文）→ 前馈。 一般与编码器同深；解码更深会略增生成质量，但推理也更慢。

前馈层宽度 d_ff（默认 1024）

每层里两层线性中间的隐藏宽度，惯例约 4 × d_model（256→1024，128→512，384→1536）。 这是参数大户之一：加宽能提升容量，对显存和时间也很敏感。

Dropout dropout（默认 0.1）

训练时随机丢掉一部分激活 / 注意力权重（第 08 课正则化）。减轻过拟合。

  • 数据少、模型大 → 可提到 0.2–0.3（加大预设用 0.2）。
  • 欠拟合（训练损失也降不下去）→ 先降到 0.05 或 0。
  • 推理时自动关闭。

Pre-LN norm_first（默认开启）

层归一化放在子层之前（Pre-LN）还是之后（Post-LN，原论文）。

  • Pre-LN（推荐）：更深时更好训，对 warmup 没那么依赖（见第 16 课 / Pre-LN 论文）。
  • Post-LN：更接近 2017 原版；小模型也能用，但学习率计划要更小心。

前馈激活函数 activation（默认 gelu）

FFN 中间层的非线性：gelu（BERT/GPT 常用）或 relu。对本规模任务差别通常不大； 想和现代配方对齐就保持 GELU（第 04、09、15 课）。

共享输出层权重 tie_embeddings（默认开启）

解码器的词嵌入矩阵与最后投影到词表的矩阵共用同一份权重（转置使用）。

  • 开：参数更少，尤其中文字表不小时省得明显；小翻译模型几乎总是值得开。
  • 关：嵌入与输出各学各的，参数更多，小数据上未必更好。

三、训练参数

训练轮数 epochs（默认 30）

完整扫过训练集的次数。一轮 = 若干 step（由句对数 ÷ 批大小决定）。快速试跑 12 轮；标准 30；加大 50。 可配合早停：设较大 epochs + 非零 patience，让验证 BLEU 不再升时自动停。

批大小 batch_size（默认 128）

每步的句对数。实现里按长度分桶组批，减少 padding 浪费。

  • 增大 → 梯度更稳、每轮步数变少、单步更吃显存；有效学习率有时需略调。
  • 减小 → 噪声更大、更新更勤、显存更省。OOM 时优先减批大小或 d_model / d_ff。

峰值学习率 lr（默认 7e-4）

预热结束时达到的最大学习率（第 05 课）。之后按 schedule 衰减。

  • 损失爆炸、NaN → 降到 3e-4–5e-4，或加长 warmup、打开梯度裁剪。
  • 损失降得极慢 → 可略升到 1e-3（快速预设），但要盯验证 BLEU 是否变差。

学习率计划 schedule（默认 cosine）

选项行为何时用
cosine预热后余弦降到峰值的约 10%默认推荐，和第 09、15 课一致
inverse_sqrt预热后按 1/√step 衰减（原论文）想复现 Attention is All You Need 配方时
constant预热后保持峰值不变短训调试；长训容易后期震荡

预热步数 warmup_steps（默认 400）

学习率从接近 0 线性升到峰值的步数。Transformer 早期梯度尺度不稳，warmup 能避免开头炸掉（第 15、16 课）。

经验：约占总步数的 5%–15%。快速试跑总步数少，用 200；更大模型 / 更多轮用 800。 Pre-LN 对 warmup 没 Post-LN 那么苛刻，但保留一段预热仍然更稳。

权重衰减 weight_decay（默认 0.01）

AdamW 的解耦权重衰减（第 08、09 课）：直接缩小权重，而不是折进梯度里。偏置和归一化参数不衰减。

  • 过拟合（训练损失很低、验证 BLEU 不升或下降）→ 提到 0.05–0.1，或加大 dropout。
  • 欠拟合 → 降到 0 或 0.001。

标签平滑 label_smoothing（默认 0.1）

不把正确答案的目标概率设为 1，而是留一点质量给其它词（原论文沿用 Inception 的做法）。 减轻过度自信、常能略提 BLEU。设为 0 即普通交叉熵；过大（>0.2）会让模型变「含糊」，短句任务上可能伤 exact match。

梯度裁剪 grad_clip（默认 1.0）

若全局梯度范数超过该值，就整体缩放回来。抑制偶发大梯度导致的发散。设为 0 表示不裁剪。 训练仍偶发爆炸时，可降到 0.5；一直很稳也可以维持 1.0。

早停耐心 patience（默认 0 = 不早停）

验证 BLEU 连续多少轮没有刷新最佳就停止。加大预设用 8：允许模型多练一会儿，但避免无效空转。 为 0 时跑满 epochs。停止时仍会保存当前权重，并在测试集上评估。

设备 device（默认 auto）

  • auto：有 CUDA 就用 GPU，否则 CPU。
  • cuda：强制 GPU（没有会报错）。
  • cpu：强制 CPU（对比速度或排查 GPU 问题时用）。

顶栏 GPU 条在 Jetson 上读 sysfs 负载；训练 / 翻译 / 评估进行时会较快刷新。

随机种子 seed（默认 42）

控制数据划分打乱与参数初始化。同一配置同一种子，结果应大体可复现（GPU 上仍可能有轻微非确定性）。 想估计「运气」带来的波动时，换几个种子各跑一遍看 BLEU 分布。

三套预设分别改了什么

预设结构要点训练要点适合
快速试跑 2+2 层，d=128，d_ff=512，约 180 万参数 12 轮，lr=1e-3，warmup=200 确认流程、看曲线、试 GPU；Jetson 上大约一两分钟量级
标准 默认：3+3 层，d=256，约 730 万参数 30 轮，lr=7e-4，warmup=400 日常对比实验的基线；短句英中已经能译得像样
加大模型 4+4 层，d=384，6 头，d_ff=1536，dropout=0.2 50 轮，lr=5e-4，warmup=800，patience=8 愿意多花时间换更高 BLEU；小数据上要注意过拟合
实测量级（Jetson，完整 cmn-eng）快速试跑验证 BLEU 约 28、测试约 29； 标准预设验证约 39、测试约 40。具体数字随驱动与随机性会有小幅波动。

训练和验证时看什么

指标含义怎么读
训练损失带标签平滑的交叉熵（每 10 步记一点）应总体下降；一直不降 → 学习率 / 数据 / 实现问题
验证损失验证集上的损失（每轮）若训练降、验证升 → 过拟合，加 dropout / 权重衰减 / 早停
验证 BLEU字级 BLEU（中文常用按字算）选 best.pt 的依据；本任务比「只看损失」更贴近观感
测试 BLEU训练结束用最佳检查点在测试集上贪心解码最终报告数字；不要用它做早停
困惑度 ppl由验证损失换算越低越好；和损失同向
吞吐 tok/s目标端 token 每秒看设备是否在干活；可与顶栏 GPU 对照
GPU 使用率当前 / 峰值利用率训练或评估时应明显抬升；长期为 0 可能落在 CPU

验证页批量评估还会给出 n-gram 精确率、长度惩罚 BP、完全一致率、源端未登录词率，以及逐句对照表 （可按句级 BLEU 排序，专门找译砸的例子）。

验证页：贪心与束搜索

  • 贪心（beam=1）：每步取概率最大的下一个字。快，适合扫测试集。
  • 束搜索（beam=4/8）：每步保留若干候选前缀再展开。通常略好、更慢；束过大收益递减。

热力图一行对应一个已生成的中文字，一列对应一个英文词（含结束符）；颜色越深，生成该字时越关注那一列。 若整行几乎均匀，说明还没学会对齐——常见于训练太短或模型过小。

调参时建议的顺序

  1. 用「快速试跑」确认能下载数据、曲线下降、GPU 有负载、短句能译。
  2. 切到「标准」跑满，记下测试 BLEU，作为基线。
  3. 一次只改一类：要么数据（max_pairs / min_freq / 长度），要么宽度层数，要么学习率计划。
  4. 过拟合 → dropout↑、weight_decay↑、patience 早停、或减小模型；欠拟合 → 加宽加深、dropout↓、多训几轮。
  5. 爆梯度 / NaN → lr↓、warmup↑、grad_clip 保持开启。
  6. 译文大量 <unk> 或红标词 → 先数据与词表，再模型。
